<img src="https://skillicons.dev/icons?i=react,ts,python,fastapi,postgres,docker" height="28" />

- A full-stack drone telemetry platform that streams live flight data to the dashboard over WebSockets, which I co-lead and own the backend service boundaries for: API endpoints, schemas and persistence layers.
- Added Clerk authentication with per-user session handling, so a user's drone flight details and logs are only ever visible to that user.

### 🗺️ Saptarishi

<img src="https://skillicons.dev/icons?i=java,spring,postgres,react,vite" height="28" />

- Turns any public GitHub repository or uploaded ZIP into an interactive dependency atlas, mapping files and folders and resolving in-repo imports into graph edges.
- Parses Java, JavaScript, TypeScript, Python, Go, C#, Rust, C, C++, Ruby and PHP, with symbol search and method call-graph exploration for the languages that support it.
- Scores repository health and flags circular imports and "god files" (large, complex and heavily connected), with a Monaco-powered code panel to read the source in place.
- Adds a churn heatmap from GitHub history and an onboarding pathfinder that suggests where to start reading, including the blast radius of each file.
- Runs analysis as background jobs with commit-SHA caching, safe ZIP extraction with archive limits, and a PostgreSQL-backed graph.

### 📈 Argus

<img src="https://skillicons.dev/icons?i=java,sqlite,maven" height="28" />

- A lightweight, offline desktop monitor that tracks CPU, memory, disk and battery in real time and warns you before your computer slows down or crashes.
- Cards move from normal to elevated to alert as values climb, and custom alert rules fire only after a limit is breached continuously, so brief spikes don't spam you with notifications.
- A ranked list of the most resource-hungry processes lets you terminate them safely, with confirmation, protected-process checks and start-time verification so a recycled PID is never killed by mistake.
- Includes a compact always-on-top widget, system tray support and light/dark themes, and every sensor is read in isolation, so a missing battery shows "N/A" instead of crashing the app.

### 🔗 URL Shortener

<img src="https://skillicons.dev/icons?i=java,spring,mysql" height="28" />

- A REST API built with Java and Spring Boot that generates and resolves short URLs with sub-second redirect latency.
- Short codes come from Base62 encoding of auto-incremented primary keys, which keeps them compact and collision-free without any retry logic.
- URL mappings and click metadata live in MySQL, with indexed short codes for constant-time lookups, plus support for link expiry and custom aliases.
